# Kitchen Hub Privacy Policy

_Last updated: 17 November 2026_

Kitchen Hub does not collect, store or share any personal data. There are no accounts, analytics, advertising or tracking.

**What stays on your iPad.** Recipes, recipe photos, timers, the shopping list, scenes and settings are stored only on your iPad. Text recognition for scanned pages and screenshots happens on the device.

**Recipe links.** When you import a recipe link, Kitchen Hub downloads that page directly from the website to read the recipe. The website receives an ordinary page request, as it would from a browser.

**Smart home scenes.** If you add a Voice Monkey API token, it is kept in the iPad's Keychain. When you run a scene, Kitchen Hub sends the token and the trigger name to Voice Monkey (voicemonkey.io) so it can start your Alexa routine. Scenes set up as web requests send only the request you configured, to the address you entered.

**Wi-Fi recipe receiver.** While Kitchen Hub is open, it can serve a page on your local network so devices on the same Wi-Fi can send it recipes. Nothing is sent over the internet.

**Deleting your data.** Deleting the app removes everything it stored.

**Contact.** Questions about this policy: open an issue at https://github.com/tobyb545/kitchen-hub or contact the developer through the App Store listing.
